# Git Commit Conventions

When writing git commits in this repository, follow these rules strictly:
1. Do not use brackets for scopes. E.g., `feat:`, `fix:`, `chore:`, NOT `feat(ui):`.
2. Ensure that the titles of all commits are unique and different from one another.
3. Include a detailed description in the commit body when applicable.
